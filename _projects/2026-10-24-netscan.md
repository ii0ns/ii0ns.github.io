> **TL;DR** — `netscan` is a single Bash script that wraps nmap and nbtscan in an interactive menu. Enter a network in CIDR notation, pick one of five scans, and get a timestamped folder with text, XML and HTML results.

---

## Overview

Running nmap well means remembering which options fit which job. `netscan` puts the common ones behind a menu so a network can be explored quickly and the results are saved in a consistent, organised way.

It is a small tool built around existing, well-known scanners: nmap does the scanning, `xsltproc` turns the XML into an HTML report, and `nbtscan` adds an optional NetBIOS name scan.

> **Legal notice:** only scan networks you own or have explicit written permission to test. The full and vulnerability scans are intrusive.

---

## Requirements

- Linux with Bash, run as root
- `nmap` and `xsltproc`
- `nbtscan` (optional, only for the NetBIOS scan)

On Debian or Kali:

```bash
sudo apt install nmap xsltproc nbtscan
```

---

## Usage

```bash
chmod +x netscan.sh
sudo ./netscan.sh
```

Enter a network in CIDR notation (for example `192.168.1.0/24`), then pick a scan.

---

## Scan Modes

| Option | Scan               | Notes                                           |
| ------ | ------------------ | ----------------------------------------------- |
| 1      | Host discovery     | Ping scan, fast                                 |
| 2      | Standard scan      | Service versions and OS detection, top 1000 ports |
| 3      | Full scan          | All ports, `-A`, slow                           |
| 4      | Vulnerability scan | nmap `vuln` scripts, intrusive and slow         |
| 5      | NetBIOS name scan  | Only finds Windows and Samba hosts              |

---

## Output

Each scan creates a timestamped folder containing `.txt` and `.xml` results and, when possible, an `.html` report. The folders are handed back to the user who ran `sudo`, so the results are not left owned by root. Pressing Ctrl-C cancels the current scan and does the same.
